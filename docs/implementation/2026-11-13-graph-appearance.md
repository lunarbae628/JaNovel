# 기준 화면 색상 조정

첨부한 화면을 기준으로 자동 분기 색을 남색·초록·갈색 중심의 차분한 팔레트로 조정했다. 사용자 지정 색과 기록 데이터는 보존한다.

추가했던 병합 이중 원·아이콘·결과 가까이에서 합류하는 경로는 사용자 요청으로 되돌렸다. `VersionGraph.jsx`와 `styles.css`는 커밋 `b5edadb` 내용으로 복원했다. 병합 기능이나 기존 부모 관계는 변경하지 않았다.

기존 52개 테스트와 색상 테스트 1개, 프로덕션 빌드로 확인한다.

후속 요청: 병합 선의 기존 경로를 유지하면서 공통 경로가 시작되는 지점부터 결과 색으로 전환한다. 노드 모양·배치·간격은 변경하지 않는다. 각 부모의 경로를 공통 지점까지만 그리고, 이후 세로 선을 결과 색으로 한 번 그린다. 기록형·지도형에 함께 적용하고 합류 색·일반 분기 유지·지도형 경로 테스트를 추가했다.
