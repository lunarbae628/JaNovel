# 전체 버전 그래프

요청: 작성안별 수정 기록은 유지하고 모든 버전·조합 출처를 볼 수 있는 전체 그래프를 추가한다. 왼쪽 상단 ‘작성안’ 텍스트와 중복 작성안 관리 아이콘은 제거한다.

- 상단 확장 아이콘으로 왼쪽 패널을 넓혀 전체 그래프를 연다. 되돌아가면 기존 작성안 목록과 개별 기록을 보여 준다.
- 기존 계보는 보존한다. 독립 작성안을 합쳐 만든 결과는 저장된 출처를 표시용 연결로만 투영하며 원본 데이터를 변경하지 않는다.
- 조합 당시 출처가 초안이거나 원본 스냅샷이 삭제된 경우 ‘참고 본문’ 노드를 만든다. 현재 편집 중인 초안과 혼동하지 않으며 클릭하면 당시 본문을 읽는다.
- 일반 노드는 선택한 본문을 열고 전체 그래프는 유지한다. 지도형·기록형 전환, 확대·축소·이동은 기존 컴포넌트를 재사용한다.
- 삭제 기능은 작성안 수정 창으로 옮기고 기존 확인 절차를 유지한다.
- 데이터 투영의 불변성·옛 계보·조합 출처·삭제된 출처를 테스트하고 전체 테스트·빌드·브라우저 동선으로 검증한다.

검증 결과: 전체 Node 테스트 69개와 프로덕션 빌드 통과. 기존 15개 스냅샷과 작성 중 1개가 모두 표시된다. 별도 테스트 공고에서 고정된 참고 초안 열기, 일반 노드의 본문 이동, 개별 기록으로 복귀, 수정 창의 삭제 진입점을 확인했다. 브라우저 경고·오류는 없었다.

독립 검토에서 전체 그래프 너비 조절이 보기를 닫는 문제와 1100px 이하에서 기존 스타일이 확장 너비를 덮는 문제를 발견했다. 그래프 너비를 별도 상태로 분리하고 전체 보기 전용 스타일을 추가했다. 키보드 너비 조절에서 수정 전 노드 0개로 전환되던 증상을 재현한 뒤 수정 후 노드 6개가 유지되는 것을 확인했다. 작은 창의 미디어 규칙은 정적으로 검토했다. 브라우저 크기 변경 도구는 실제 뷰포트를 1280px로 유지해 1024px 시각 검증은 수행하지 못했다.
