# 작성 중심 비교와 활성 초안 그래프

사용자 승인: ‘작성 → 다른 안과 비교 → 좋은 표현 반영 → 스냅샷’을 기본으로 시험한다. 그래프의 작성 중 노드가 너무 많다는 후속 지적을 함께 반영한다.

- [x] 비교 모델: 완성된 현재 초안을 유지하고 선택한 참고 구절만 교체한다. 추가·삭제·반복 문구·직접 편집·불변 스냅샷을 테스트한다.
- [x] 기본 그래프는 현재 작업 브랜치의 초안 하나만 보여 준다. 다른 초안은 보관하고 분기 선택으로 전환한다. 펼친 전체보기에는 모두 표시한다. 모델 데이터와 표시용 필터를 분리해 숨긴 초안을 삭제하지 않는다.
- [x] 편집 화면: 노드 클릭으로 기록 읽기, 작성 중과 비교, 왼쪽 참고 본문 구절 반영, 오른쪽 초안 직접 편집, 작성으로 복귀. 일반 비교에서 별도 병합·저장은 요구하지 않는다. 고급 3열 병합은 유지한다.
- [x] AI 수정안은 별도 비교 모달 대신 같은 두 칸 비교 영역을 사용한다. 현재 초안을 완성된 상태로 보여주고 부분 반영을 지원한다.
- [x] 활성 브랜치를 문항에 선택적으로 보관한다. 기존 데이터는 첫 브랜치로 시작하며 새 분기/병합 결과 URL은 해당 초안을 선택한다. 과거 스냅샷 읽기만으로 활성 초안을 바꾸지 않는다.
- [x] 테스트·빌드, 별도 localhost 원점의 브라우저에서 흐름과 보존을 검증한다. 실제 작업 중인 127.0.0.1 데이터는 검증용 입력으로 바꾸지 않는다.

현재 호출 구조를 유지하며 Editor.jsx, VersionGraph.jsx, Diff.jsx에 연결한다. 비교 구절 계산과 그래프 필터는 순수 함수로 테스트한다. 원본 Docsa 및 Figma 디자인은 수정하지 않는다. Git 작업은 범위에 없다.

## 검증 결과

- Node 테스트 29개 통과, 프로덕션 빌드 통과.
- 브라우저에서 기본 그래프의 활성 초안 1개 / 전체보기의 분기별 초안 표시를 확인했다.
- 다른 분기 전환, 과거 기록 읽기, 새로고침 후에도 작업 분기와 각 초안이 보존된다.
- 과거 구절과 외부 AI 예시 수정안의 부분 반영, 직접 작성한 결론 보존, 스냅샷 생성 후 이전 기록 불변을 확인했다. 실제 AI 연결은 추가하지 않았다.
- 콘솔 오류·경고 없음. 화면 기록: `_workspace/2026-11-11-writing-flow/comparison.png`.

이 문서의 기본 그래프 정책이 이전 구현 기록의 ‘모든 분기의 작성 중 노드 표시’를 대체한다. 원본 데이터의 분기별 초안은 삭제하거나 통합하지 않는다.

## 비교 화면 후속 수정

- 사용자 요청에 따라 변경 구절 표시는 왼쪽 참고 본문에만 남긴다.
- 오른쪽은 편집할 분기의 초안만 선택하며 항상 직접 수정할 수 있다. 스냅샷은 왼쪽에서 참조해 원본을 보호한다.
- 오른쪽의 차이 표시용 겹침 본문과 강제 스크롤바를 제거했다. 짧은 본문에서 확보되던 11px의 빈 스크롤바 공간을 없앴다.
- 메인 브랜치로만 병합하는 제한은 제안 단계이며 적용하지 않았다.

## 분기별 작성 중 표시 재검토

- 사용자 후속 요청으로 기본 그래프에서도 모든 분기의 작성 중을 다시 표시한다. 위의 ‘활성 초안 하나만 표시’ 정책을 대체한다.
- AI 사이드바 앞의 6px 빈 띠를 제거했다. 조절 손잡이는 경계 위의 8px 영역으로 유지해 드래그·키보드 너비 조절을 지원한다.
- 스냅샷·브랜치 삭제와 작성 중 닫기는 동작 방식 확인 후 구현할 제안이다. 삭제·숨김은 아직 추가하지 않았다.

### 기록 정리 제안 — 결정 대기

- 스냅샷·브랜치 삭제: 휴지통 이동 후 복원 가능하게 하는 방식을 추천한다. 다른 기록이 부모로 참조하는 경우 그래프 연결을 보존해야 한다.
- 대안: 참조되지 않는 기록만 영구 삭제하도록 제한한다. 분기·병합이 많을 때 정리할 수 있는 범위가 좁다.
- 작성 중 닫기: 변경 내용은 스냅샷으로 남기고 작업 노드를 닫는 방식을 추천한다. 분기를 다시 편집하면 작업 노드가 나타난다. 변경 내용 버리기는 별도 선택으로 구분한다.
