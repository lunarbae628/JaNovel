# JaNovel Figma 디자인 작업 기준

2026-11-06 · 기존 시안을 바탕으로 한 디자인 초안 제작 · 개발 구현 전

## 첫 작업 범위

자소서 작성 화면과 버전 비교 화면을 먼저 다듬는다. 기존 3열 구조를 기준으로 데스크톱 작성·비교, 양옆 패널을 접은 작성 상태, 휴대폰 작성 상태와 스냅샷 이름·설명 입력창을 검토한다. 이 기준을 확인한 뒤 지원 현황·캘린더·공고 등록과 나머지 흐름으로 확장한다.

## 유지할 사용자 결정

- 왼쪽은 선택한 문항의 버전 그래프, 가운데는 작성·비교·병합, 오른쪽은 문항별 AI 대화다.
- 문항 탭과 비교·병합·스냅샷은 가운데 도구 줄에 모은다. 글자 수는 문항 바로 옆에 둔다.
- 회사 헤더 왼쪽에는 지원 현황으로 돌아가기, 오른쪽에는 지원하러 가기를 둔다.
- 좌우 접기 버튼은 각 패널 안쪽 상단에 두고, 접은 뒤에도 펼칠 수 있어야 한다.
- 피드백 요청은 채팅 입력 영역에 둔다. 별도 보내기 버튼은 추가하지 않는다.
- 섹션은 무채색, 선택·스냅샷·수정 표현은 파란색을 쓴다. 지원하러 가기는 차콜을 유지한다.
- 빨간 삭제선, 그라데이션, 장식 카드·통계, 반복 설명문은 추가하지 않는다.

## 시각 기준

현재 본문색 #302B27, 포인트 #274690, 보조 포인트 #576CA8, 선택 배경 #EDF1FA를 기준으로 한다. 편집면은 흰색, 그래프는 #F7F7F8, 채팅은 #FAFAFA로 구분한다. 글의 가독성, 도구의 정렬과 간격을 먼저 조정하며 파란색의 사용 면적을 늘리지 않는다.

한글 본문 폰트는 현재 시스템 폰트인 Apple SD Gothic Neo를 우선 확인한다. Figma에서 사용할 수 없으면 한글을 지원하는 대체 폰트를 선택하고 선택 근거를 기록한다. 한글 본문을 지원하지 않는 폰트를 임의로 적용하지 않는다.

## 편집 가능한 결과물

Figma 화면은 텍스트·레이아웃·컴포넌트를 수정할 수 있는 레이어로 만든다. 반복 버튼·탭·입력은 재사용하고, 색상·간격·글꼴 기준을 화면 사이에 공유한다. 완성 화면의 캡처 이미지를 디자인 레이어 대신 사용하지 않는다.

## 검토 기준과 후속 항목

긴 문항·스냅샷 이름에서 잘림과 겹침을 확인하고, 비교 시 본문을 읽을 폭을 확보한다. 양쪽 패널을 접어도 문항 선택과 지원 현황 이동이 유지돼야 한다. 기존 시안에서 동작하는 기능을 정적인 디자인이 실제로 구현했다고 표시하지 않는다.

서비스 내부에서 개인 AI와 채팅하는 경험은 2026-11-07 사용자 확정 요구다. 실행·계정 연결·호출·사용량 경로는 기술 검증 전이다. 우측 대화 영역을 외부 ChatGPT로 이동하는 기본 동선으로 바꾸지 않는다. 제출본, 복원, 공고·일정 수정, 저장 실패와 연결 실패 상태는 후속 화면으로 다룬다.

## Figma 초안

사용자가 선택한 개인 팀 ‘배문성's team’에 [JaNovel · 제품 디자인](https://www.figma.com/design/ArLSPAcNklUKhcpk8V4zyf?node-id=5-530)을 생성했다.

| 화면 | Figma 노드 | 크기 |
| --- | --- | --- |
| 작성 | 5:530 | 1440 × 900 |
| 버전 비교 | 5:647 | 1440 × 900 |
| 집중 작성 | 5:790 | 1440 × 900 |
| 휴대폰 작성 | 5:855 | 390 × 844 |
| 스냅샷 이름·설명 | 5:912 | 1440 × 900 |

기존 시스템 폰트가 Figma에 없어 사용 가능한 Noto Sans KR을 적용했다. 버튼과 접기 아이콘은 Simple Design System 자산을 재사용하고, 색상·텍스트 스타일은 JaNovel 기준으로 연결했다. 화면은 편집 가능한 텍스트·오토레이아웃·인스턴스로 구성했으며 완성 화면 이미지로 대체하지 않았다.

작성·비교·집중 상태와 스냅샷 입력창 사이에 검토용 전환을 연결했다. 모든 버튼·문항 탭의 실제 제품 동작을 구현한 것은 아니다. 지원 현황으로 돌아가는 버튼의 목적지 화면은 다음 디자인 범위에서 연결한다.

다섯 화면을 렌더링해 문항 바로 옆 글자 수, 문항 탭 폭, 휴대폰 제목 줄바꿈, 비교 여백과 입력창을 보완했다. 최종 레이어 검사에서 보이는 텍스트가 화면 경계를 넘지 않았고, 한글 폰트는 Noto Sans KR로 일치했다. 화면 안의 이미지 채우기는 0개다. 검증 기록과 생성 상태는 로컬 `_workspace/2026-11-06-figma/`에 보관한다.

이후 비교 하단 정리와 병합 그래프 예시를 추가했다. 해당 수정의 근거·상태와 최종 캡처 제한은 [비교·그래프 검토](10-graph-and-compare-review.md)를 따른다. 위 다섯 화면의 이전 검증을 후속 수정본의 렌더링 검수로 간주하지 않는다.

2026-11-07에는 Talk to Figma로 주변 노드와 사이드바 확장 상태를 반영하고 작성·비교·확장 화면을 캡처해 확인했다. 현재 확장 화면은 `15:342`이며 큰 카드 대신 작은 원형 노드를 사용한다. 남은 흐름과 다음 디자인 순서는 [Figma 검토와 다음 화면](11-design-review-and-next-screens.md)에 정리했다.

같은 날 추가 요청으로 비교를 변경 구절 강조로, 병합을 원문·결과·수정본 3열로 바꿨다. 전체 그래프는 연결선 레인과 기록 이름 영역을 분리하고 사이드바 폭을 360px로 줄였다. 최신 수정 범위는 [Docsa 기준 디자인](13-docsa-keyword-compare-merge.md)을 따른다.

2026-11-08에는 사용자 지시에 따라 AI 연결 실험을 뒤로 미루고 공고 입력·지원 현황·달력·제출본·예외 상태의 디자인을 먼저 보완했다. 현재 범위와 화면별 링크, 클릭 전환 검증의 한계는 [핵심 화면 검토](14-core-screens-and-review.md)를 따른다.
