# 비교 화면 수정과 대표 디자인 선택

2026-11-09 작성 · 2026-11-10 방향 선택 반영

사용자가 A 바탕에 C의 회색 비교 정보 줄과 블루 지원 버튼을 결합하는 방향을 수락했다. 선택한 조합과 아이콘 수정은 [20-icon-refinement.md](20-icon-refinement.md)를 따른다. 아래 A/B/C 표는 선택 전 대안의 기록이다.

## 반영한 수정

- 왼쪽 `버전 기록` 제목을 제거했다. `Q1 · 기본`의 `기본`은 기본 갈래를 뜻하던 임시 라벨이었다. `Q1` 또는 `Q2`만 남기고 패널 헤더에 올렸다.
- 비교의 `117 → 306자`를 제거하고 각 열에 `117자`, `306자`를 표시한다. 작성 화면의 글자 수는 기존대로 문항 옆에 둔다.
- 비교 대상 선택은 32px 높이의 작은 선택창으로 바꿨다. `작성 중`과 같은 대상 이름은 유지하며 기존 대상 선택 연결도 유지한다.
- 중앙의 작성·병합·분기·스냅샷을 같은 계열의 윤곽 아이콘으로 바꿨다. 패널 접기와 그래프 전체/주변 보기도 아이콘으로 정리했다. 실제 프론트 구현에서는 각 아이콘에 툴팁과 접근성 이름을 제공한다. 현재 Figma에서 툴팁 동작을 구현했다는 의미는 아니다.
- 본문은 Noto Sans KR 14px / 24px, 문항은 18px / 28px로 줄였다. 키워드 단위 블루 비교 표시는 유지한다.
- 중앙 도구와 채팅 헤더를 48px로 맞췄다. 큰 구분선의 실제 세로 좌표도 대조했다.

아이콘은 [Lucide 공식 SVG](https://github.com/lucide-icons/lucide/tree/main/icons)를 사용한다. 외부 래스터 이미지를 붙이지 않고 편집 가능한 벡터와 컴포넌트를 유지한다.

동일한 문항, 스냅샷, 작성 중 초안, 그래프와 AI 응답을 사용한다. 새 기능은 추가하지 않았다. 새 시안은 비교 화면 세 개뿐이다.

## 확인한 범위

- 기존 작업 화면 214개와 시안 3개를 읽어 총 217개를 점검했다.
- 중앙·채팅 구분선이 함께 있는 191개 화면은 세로 좌표 차이가 0px였다. 나머지 26개는 두 구분선이 함께 표시되는 구조가 아니다.
- 비교 화면 147개의 본문 열 294개는 14px / 24px였으며 각 글자 수가 해당 텍스트 길이와 일치했다. 현재 예시는 JavaScript 문자열 길이를 사용한다. 실제 제품의 공백·줄바꿈·유니코드 글자 수 규칙은 구현 전에 명시한다.
- 중앙 작업 아이콘 507개의 텍스트 라벨 숨김을 확인했다. 원래 버튼 노드를 유지하여 연결된 클릭 동작을 보존했다. 기존에 비활성화된 동작까지 새로 연결한 것은 아니다.
- A/B/C를 PNG로 내보내 확인하고, Figma 앱에서도 세 프레임이 나란히 보이는 것을 확인했다.

이 검사는 이번 시각 수정 범위다. 모든 기존 화면을 포인터로 왕복하거나 실제 저장·AI 호출을 검사한 결과는 아니다. 기존 기록 이후의 연속 분기·병합 시연 제한은 18번 문서에 남아 있다.

검증 및 미리보기는 로컬 `_workspace/2026-11-09-concepts/`에 둔다. `verification.json`은 마지막 읽기 결과다. 재현 도구는 `scripts/figma/compact-concepts.mjs`, 플러그인 수정은 `compact-concepts-tools.js`와 `install-product-tools.py`에 있다. 수정 전에 기존 연결 채널과 파일을 확인해야 한다.

작업 중 Figma는 로컬 변경사항의 온라인 동기화를 기다린다고 표시했다. 웹 링크가 오래된 상태라면 데스크톱 파일과 로컬 PNG를 기준으로 확인한다.
