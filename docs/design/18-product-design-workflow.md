# JaNovel 제품 디자인 고도화

2026-11-09 · 작업 기준

## 방향

긴 글을 쓰고 여러 버전을 확인하는 작업 도구로 다듬는다. 기존 3단 구성, 문항별 그래프, 키워드 비교, 무채색 바탕과 블루 포인트를 유지한다. 화면을 크게 차지하는 안내 문구, 장식 카드, 그라데이션, 홍보 페이지용 애니메이션은 추가하지 않는다.

UI UX Pro Max를 프로젝트의 `.agents/skills/ui-ux-pro-max`에 설치했다. [공식 원본](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)의 접근성·내비게이션·정보 밀도·상태 표시 원칙을 사용한다. 자동 추천의 랜딩 페이지 구성, 영문 폰트, 색상 교체는 이 제품에 적용하지 않는다. taste-skill의 회사 웹사이트 중심 구성도 적용하지 않는다.

## 순서와 완료 기준

1. `17-design-review.md`의 오류를 수정한다. 회사·문항·선택 버전·병합 결과를 이동 전후 문자열로 대조한다.
2. 패널 접기는 독립적인 인터랙티브 컴포넌트로 만든다. 본문 화면으로 이동하지 않고 해당 패널만 접힌다. 비교 대상 유지와 접힌 영역의 내용 숨김을 미리보기에서 확인한다.
3. 작성·비교 화면의 대표안을 먼저 다듬는다. 텍스트 크기, 문단 간격, 작업 버튼, 그래프 선택 표시, 채팅 입력 영역을 통일한다. 편집 가능한 Figma 레이어를 유지한다.
4. 대표안을 확인한 다음 지원 현황·캘린더·공고 등록에 확장한다. 화면마다 빈 상태·실패·진행 중 상태는 필요한 것만 설계한다.

## 시각 기준

| 역할 | 기준 |
|---|---|
| 본문 | Noto Sans KR, 14px / 24px — 2차 사용자 검토 반영 |
| 문항 | 18px / 28px, Bold; 작성 화면은 문항 옆 글자 수, 비교 화면은 각 열에 개별 글자 수 |
| 작업 라벨 | 14px / 22px, Medium |
| 보조 정보 | 12px / 20px, 읽을 수 있는 대비 유지 |
| 주요 동작 | #274690, 흰 글자; 한 영역에서 강조를 제한 |
| 본문 글자 | #302B27 |
| 패널 | #F7F7F8 / #FAFAFA, 얇은 구분선 |
| 선택 / 변경 구절 | 선택 행 #EDF1FA, 비교 구절 #274690, 병합 후보 배경 #DCE4F6 |
| 버튼 | 36px 기본 높이, 작업 아이콘·비교 대상 선택 32px; 중앙 도구·채팅 헤더 48px |
| 간격 | 4 / 8 / 12 / 16 / 24 / 32px |

Figma 무료 플랜에서 변수로 프로토타입 상태를 바꾸는 기능은 사용할 수 없다. [공식 안내](https://help.figma.com/hc/en-us/articles/14506587589399-Use-variables-in-prototypes)에 따라 선택 예시는 유한한 시연 상태로 구현한다. 접기는 무료로 가능한 컴포넌트 변형 전환을 사용하여 화면 복제를 줄인다. 자유 입력·실제 저장·AI 호출은 구현 단계의 검증 항목이다.

## 검증 기록

수정 및 검증이 끝난 항목만 아래에 추가한다. 설치나 연결 성공은 화면 완료로 간주하지 않는다.

### 1차 반영 결과

- 기존 무채색·블루 팔레트를 유지했다. 작성 본문 폭을 720px로 제한하고 본문 16px / 28px, 문단 간격 20px, 작성 도구 높이 48px로 정리했다. 문항 바로 옆의 글자 수와 채팅 안의 피드백 요청 위치를 유지했다.
- 비교 본문을 고정된 줄 조각에서 너비에 맞춰 줄바꿈되는 텍스트로 바꿨다. 바뀐 단어·구절만 블루로 표시하고, 좌우 열 구분선과 비교 대상 선택창의 테두리를 추가했다.
- 회사별 처음 작성 화면 6개를 분리하고 Q2의 AI 비교를 Q2 원문·제안·대화로 연결했다. 빈 문항에서 사용할 수 없는 동작은 비활성 상태로 표시한다.
- 제출 버전의 Q1 3종 × Q2 2종, 총 6개 조합에서 선택 화면과 고정된 본문이 같도록 연결했다.
- 일반 스냅샷·병합·AI 제안 채택의 결과 12종을 연결했다. 이름·설명과 선택한 구절을 결과에 표시하고 새 기록을 그래프에 추가했다. 새 기록의 축약 그래프는 직접 부모·선택 기록·작성 중 초안으로 제한했다.
- 양쪽 패널은 별도 화면 이동 대신 컴포넌트의 변형을 전환한다. 접힌 상태에는 펼치기 버튼만 남긴다. 전체 그래프도 같은 왼쪽 패널을 400px로 넓혀 표시하며 본문과 비교 대상은 유지한다. 노드는 작은 원형으로 유지하고 같은 위치의 중복을 방지했다.
- Figma 미리보기 시작점 100개를 지원 현황·자소서 작성·버전 비교·캘린더 네 개로 정리했다.

### 확인한 범위

2026-11-09 최종 Figma 읽기 검사 591개를 통과했다. 회사별 작성 진입, 제출 버전 6개 조합, 새 기록 결과 12종, 기존 비교 상태 76개, 패널 인스턴스 358개의 전환과 폰트를 대조했다. 전체 그래프 48종에서 원형 노드가 겹치지 않는지 확인했다. 새 기록의 축약 그래프 18개 컴포넌트에서도 관련 없는 기록이 끼어들지 않는지 별도로 확인했다.

미리보기에서는 그래프 노드로 본문을 열고, 작성 중 초안과 비교한 상태에서 전체 그래프를 펼쳐도 선택한 본문과 대상이 유지되는 것을 확인했다. 작성 화면의 접기도 직접 확인했다. 모든 조합을 포인터로 왕복한 검사는 아니다. 한글 폰트는 Noto Sans KR로 일치했다.

검증 원본과 캡처는 `_workspace/2026-11-09-product-design/`에 둔다. `verification.json`, `compact-verification.json`, `trees-after.json`, `reactions-after.json`이 읽기 결과다. 점검 도구는 `scripts/figma/verify-product-design.mjs`다.

### 다음 검토

2차 수정과 대표 화면 A/B/C 선택은 [19-comparison-concepts.md](19-comparison-concepts.md)를 따른다. 아래 1차 결과의 16px 본문·큰 비교 선택창은 2차에서 변경했다. 대표 콘셉트 선택 전에는 지원 목록·캘린더·공고 등록에 시각 스타일을 확장하지 않는다.

이번 결과는 데스크톱 작성·비교 화면의 1차 고도화다. 지원 목록·캘린더·공고 등록의 시각 기준 통일, 좁은 화면 배치, 빈 상태·실패·진행 중 상태를 이어서 다듬는다. 새 기록에서 다시 분기·병합을 연속 수행하는 흐름은 기존 예시 연결을 재사용하는 부분이 있어 별도로 보완해야 한다. 제한된 Figma 시연을 실제 저장·입력·무제한 버전 생성이 되는 제품으로 판단하지 않는다.

최종 확인 당시 Figma 앱은 변경사항을 로컬에 저장했으며 온라인 동기화를 기다린다는 메시지를 표시했다. 웹 링크에 최신 상태가 반영됐는지는 확인하지 못했다. 로컬 캡처로 현재 시안을 확인할 수 있다.
