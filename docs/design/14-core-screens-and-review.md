2026-11-08 · Figma 화면·상태 보완 · 제품 구현 및 AI 연결 실험 전

> 후속 변경: 그래프 노드 메뉴·달력 표시·실제 Figma 전환 연결과 검증 결과는 [15번 문서](15-node-actions-calendar-prototype.md)를 따른다. 아래의 전환 미연결 설명은 이 검토본 작성 당시 상태다.


## 작업 순서와 현재 상태

사용자 지시에 따라 디자인 검토를 먼저 마무리하고 AI 연결 실험은 그다음에 진행한다. 웹 내부 채팅 요구와 자소서 버전관리 중심은 유지한다. 이번 작업은 화면 디자인이며 인증·MCP·모델 호출·DB 저장을 구현한 것이 아니다.

기존 작성·비교·그래프·분기·병합 스타일에 20개 화면·상태를 추가했다. 편집 가능한 Figma 텍스트·프레임·컴포넌트를 사용했다. 신규 화면과 이번에 변경한 기존 화면을 합쳐 25개를 레이어 기준으로 확인했다. 모바일 작성 초안·기존 스냅샷·분기 입력창 전체를 이번에 새로 검수한 것은 아니다.

현재 상태는 **핵심 데스크톱 화면과 주요 예외 상태가 있는 검토본**이다. 새 화면의 Figma 클릭 전환을 모두 연결하고 왕복 검증한 상태는 아니므로 프로토타입 완료나 제품 구현 준비 완료로 표시하지 않는다.

## 검수 결과와 한계

- 최신 레이어 검사 25개 화면에서 한글 폰트는 Noto Sans KR이고 이미지 채우기는 0개다. 완성 화면 캡처로 Figma 레이어를 대체하지 않았다.
- 검사한 텍스트의 경계가 해당 화면 바깥으로 나간 사례는 0개다. 이는 모든 부모 컨테이너의 잘림, 스크롤·반응형 동작·긴 문구 스트레스 테스트까지 보장하는 검사는 아니다.
- 신규 화면을 캡처해 시각 검토했다. 목록의 과한 상태 버튼, AI 채택 버튼 위치·후보 이름, 달력 주 구분선, 일정·절차 대화상자의 배경 맥락, 수정 창 제목과 Q2 탭 크기를 보완했다.
- 기존의 무채색 섹션·파란 포인트·차콜 외부 지원 링크, 작은 원형 그래프, 변경 구절 강조, 중앙 스냅샷·분기·병합 원칙을 유지했다.
- 고객 AI 연결·로그인 설정은 실제 인증·제공 경로를 검증한 뒤 확정한다. 이번에 지원되지 않는 인증을 되는 것처럼 표현하는 연결 설정 화면을 추가하지 않았다.
- 실제 문서 저장·복구·동시 편집·일정 반영·제출본 불변성·공고 추출·AI 품질은 아직 제품 구현과 시험이 필요하다.

작업·검사 기록은 `_workspace/2026-11-08-design/`의 `initial-receipt.json`, `receipt.json`, `review.json`에 보관한다. 생성·보완 소스는 `scripts/figma/finish-design.mjs`, 기존 로컬 플러그인 전송 보조 도구는 `talk-channel.mjs`, 검수 소스는 `review-design.mjs`다. 이 도구들은 디자인용 Talk to Figma 연결을 사용하며 JaNovel 제품의 AI 연결 코드가 아니다. 원본 Docsa 코드는 수정하지 않았다.

## 다음 순서

사용자가 공고 등록 → 지원 상세 → Q1·Q2 작성 → 분기·병합 → AI 후보 검토 → 제출본 → 달력 흐름의 화면을 검토한다. 필요한 시각 수정을 반영하고 새 화면 전환 연결을 마친 다음 AI 연결 실험과 구현 계획으로 넘어간다. 주간 추천·음성 면접·결제·랜딩 페이지는 현재 디자인 범위에 포함하지 않는다.
