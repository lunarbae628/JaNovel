# 자소서 작성·비교 와이어프레임 검토

2026-10-31 · 제품 구현 전

최신 기준은 [문항 선택과 문항별 버전 그래프](04-question-versioning.md)에 정리했다. [3열 배치](03-three-column-workspace.md)는 유지한다. 데스크톱에서는 세 영역을 함께 열고 가운데에서 작성·비교를 전환한다. 사용자가 이전 안을 복잡하다고 지적해 작성·버전 비교·피드백 대화로 분리했다.

작성 화면에서 시작하는 통합 미리보기는 [작성·지원 현황 왕복](wireframes/application-editor.html)이다. 왼쪽 위 ‘← 지원 현황’에서 목록·캘린더로 이동할 수 있다. 좌우 접기 버튼은 각 패널 안쪽 상단에 두고 접힌 자리에서 다시 펼친다.

이전의 한 화면에 버전 이력·후보·제출본을 모두 배치하는 안, 문단별 화살표와 삭제 상자, 반복적인 기능 설명은 폐기했다. 비교 표현은 원문 그대로 + 수정본 파란색 강조를 유지한다.

검토할 흐름은 작성 → 과거 버전 비교, 작성 → 피드백 채팅 → 응답 수정안 비교 → 적용이다. 두 흐름이 명확히 구분되는지와 본문을 읽는 데 불필요한 요소가 없는지를 확인한다.

현재 미리보기는 로컬 예시이며 실제 AI·MCP·자동 저장·DB 연결은 없다. 실제 내부 채팅 도입 경로와 비용은 아직 확정하지 않았다.
