# 선택한 디자인 방향과 아이콘 수정

2026-11-10

## 방향

A의 흰 회사 헤더와 본문 여백을 유지하고 C의 회색 비교 정보 줄, 블루 지원 버튼을 결합한다. 기존 작업 화면 214개와 선택한 A 시안에 적용했다. 지원 현황·캘린더·공고 등록을 이번에 새로 디자인한 것은 아니다. B/C는 이전 대안으로 남긴다.

## 아이콘 선택

사용자가 두꺼운 아이콘과 서로 구분하기 어려운 분기·병합을 지적했다. [Lucide 선 두께 안내](https://lucide.dev/guide/lucide/basics/stroke-width), 공식 [split](https://lucide.dev/icons/split)·[merge](https://lucide.dev/icons/merge), [Tabler 아이콘](https://tabler.io/icons?icon=arrows-split)을 비교했다. 기존 계열을 유지하면서 동작 방향을 드러내는 Lucide 공식 SVG를 선택했다.

| 동작 | 이전 | 적용 |
|---|---|---|
| 분기 | 작은 원형 노드의 git-branch | 하나에서 두 방향으로 갈라지는 split |
| 병합 | 작은 원형 노드의 git-merge | 두 경로가 한 방향으로 모이는 merge |
| 작성 | 밑줄이 붙은 pencil-line | 단순한 pencil |
| 좌우 패널 접기·펼치기 | 상자·분할선·화살표가 겹친 그림 | 해당 이동 방향의 단일 chevron |
| 전체·주변 그래프, 비교 대상, 스냅샷 | 기존 공식 glyph | 같은 모양에서 선 두께 통일 |

직접 도형을 그려 대체하지 않았다. 공식 SVG 경로를 유지하고 18px 크기, 실제 벡터 선 두께 1.25px, 중성 회색 `#656B76`로 통일했다. 버튼 클릭 영역은 32px다.

이전 아이콘은 SVG 프레임을 18px로 줄였지만 실제 벡터 선이 2px로 남아 있었다. 수정 전 읽기 결과에서 11개 마스터 모두 이를 확인했다. 수정 후 각 벡터의 선 두께를 명시적으로 설정했다. 흐린 투명도로 굵기를 가린 것이 아니다.

## 검증과 한계

추가 사용자 요청으로 병합·분기 SVG만 중심을 기준으로 180도 돌렸다. 병합은 위의 두 경로가 아래 하나로 모이고, 분기는 위의 한 경로가 아래 둘로 갈라진다. 그래프의 위→아래 흐름과 맞추며 선 두께와 클릭 연결은 유지한다.

- 11개 아이콘 마스터의 실제 선 두께가 모두 1.25px임을 다시 읽어 확인했다.
- 작성 `5:530`, 비교 `67:2743`, 선택 시안 `94:113338`의 클릭 연결을 수정 전후 대조했다. 노드 ID와 연결 내용은 일치했다.
- 기존 화면·시안 217개의 점검에서 본문 크기, 개별 글자 수, 헤더 구분선 정렬의 오류가 없었다.
- 선택한 비교 화면과 도구 줄을 Figma에서 PNG로 내보내 시각적으로 확인했다.

아이콘은 동작을 구분하는 단서다. 실제 프론트에서는 `작성`, `병합`, `분기` 등의 툴팁과 접근성 이름도 제공해야 한다. 이번 작업에 Figma 툴팁 동작이나 실제 웹 구현은 포함하지 않았다.

선택 화면: [Figma](https://www.figma.com/design/ArLSPAcNklUKhcpk8V4zyf?node-id=94-113338).

원본·라이선스는 `scripts/figma/assets/`, 변경 도구는 `refine-icons-tools.js`와 `refine-icons.mjs`에 둔다. 기존 컴포넌트 키와 ID를 유지하고 출처 메타데이터로 실제 glyph를 기록한다. 로컬 읽기 기록·미리보기는 `_workspace/2026-11-10-icons/`에 있다. Git 커밋·푸시는 하지 않았다.
