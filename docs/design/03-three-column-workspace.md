## 화면 배치

이전의 작성·채팅을 별도 화면으로 나누던 안은 사용자의 후속 요청에 따라 변경했다. 데스크톱에서는 좌측 버전 그래프, 가운데 작성 섹션, 우측 AI 채팅을 동시에 보여 준다. 그래프와 채팅은 유지하고 가운데 영역만 작성·과거 버전 비교·AI 수정안 비교로 전환한다.

좌측 그래프의 스냅샷을 선택하면 가운데에서 현재 작성본과 비교한다. ‘작성 중’을 선택하면 편집으로 돌아온다. 기본 예시는 v1에서 v2와 다른 도입의 v2-A로 나뉜다. 선택한 스냅샷에서 분기하거나 AI 수정안을 적용하면 부모에 연결된 새 노드를 만든다. 후속 사용자 요청으로 문항별 답변을 기록 단위로 두고, 가운데 섹션 안에 스냅샷·분기·문단 선택 병합을 추가했다. 최신 규칙은 [문항별 버전관리](04-question-versioning.md)와 [스냅샷·분기·병합](07-snapshots-branch-merge.md)을 따른다. 그래프 직접 편집은 포함하지 않는다.

AI 피드백은 오른쪽 대화에서 요청한다. 응답의 ‘비교하기’는 가운데에 요청 당시 원문과 수정안을 연다. 수정안을 적용하면 새 버전을 남긴다. 글과 메시지 초안은 응답 도착이나 화면 전환에도 유지하며, 문항별 대화는 분리한다. 요청 후 글이 바뀌면 오래된 후보의 적용을 차단한다.

설명문·배지·범례·장식 카드는 다시 추가하지 않는다. 글을 쓰는 영역과 채팅의 관계를 세로 구분선과 배경색으로 드러낸다.

## 화면 크기

데스크톱에서는 세 영역이 나란히 보인다. 태블릿 폭에서는 그래프 옆의 작성 영역 아래에 채팅을 배치한다. 휴대폰에서는 버전·작성·채팅 탭으로 전환해 편집 폭을 확보한다. 모바일 대응 방식은 이번 작업에서 제안한 선택이며 최종 제품 정책은 디자인 검토에서 조정할 수 있다.

## 범위와 확인

이 문서는 기본 3열 배치 기준이다. [이전 디자인 방향과 조사](02-design-direction.md)의 불필요한 텍스트·장식 최소화 원칙은 유지한다. 후속 요청으로 기본 분기와 문단 선택 병합을 미리보기에 추가했다. 실제 저장 구조와 자동 충돌 해결 범위는 후속 설계 대상이다.

브라우저에서 3열 표시, 그래프 선택·분기 저장, 과거·AI 비교, 후보 적용 후 노드 추가, 중복·오래된 후보 적용 방지, 대기 중 작성 내용 보존, 메시지 초안 유지와 문항별 응답 분리를 확인했다. 1200·1024·736·375·320px에서 가로 넘침과 실행 오류가 없었고 모바일 영역 전환도 확인했다. 화면 이미지는 프로젝트 `_workspace/2026-10-31-three-column/`에 있다.

모든 본문·그래프·AI 응답은 로컬 예시다. 실제 Docsa 코드, DB, MCP, 계정 인증, API 호출, 영속 저장을 구현한 것이 아니다. 브라우저 새로고침 시 초기화된다. 과거 버전에서 작성하는 동작은 현재 초안을 교체하므로, 정식 제품에는 미저장 변경 확인이 필요하다. 실제 AI 연결·비용 경로는 계속 기술 검증이 필요하다.
