# 조사 근거와 한계

2026-10-15~21에 본 공개 안내와 코드의 범위다. 로그인 후 기능, 유료 기능의 품질과 성능, 사용자 수·합격률·시간 절약 수치는 검증하지 않았다. 제품의 현재 기능과 결정은 [제품 기획](01-product-plan.md)을 기준으로 한다.

| 자료 | 당시 기획에 참고한 점 |
| --- | --- |
| [TIO](https://tiokorea.com/) | 공고를 받아 원문과 확인 화면으로 이어 가는 흐름의 참고 사례 |
| [자소설닷컴](https://jasoseol.com/) | 채용달력, 공고와 자소서 작성의 연결 |
| [Teal Resume Builder](https://www.tealhq.com/tools/resume-builder) | 이력서 작성과 회사별 지원 관리의 연결 |
| [Huntr 도움말](https://help.huntr.co/en/articles/10477521-what-is-huntr) | 지원 관리와 여러 이력서를 다루는 흐름 |
| [Docsa 프론트엔드](https://github.com/lunarbae628/Docsa_FE) | 답변 수정 전후에서 변경 구절을 보여주는 방식 |

경쟁 서비스에 국내 자소서 문항 단위 이력과 동일한 기능이 있는지까지 확인하지 않았다. JaNovel의 사용 가치는 [실사용으로 검증](02-critical-review.md)한다. 웹 내부 AI 연결의 제공 범위와 비용도 [별도 연결 실험](05-local-agent-chat-review.md)에서 확인한다.
