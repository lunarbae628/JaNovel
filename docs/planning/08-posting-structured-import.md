# 공고 가져오기 JSON 구조화

링크는 기존 HTTP·Chromium 경로로 본문을 확보한다. 외부 링크 검사와 공고 영역 캡처는 기존 구현을 재사용한다. 첨부 이미지와 링크 재시도 캡처는 모델의 이미지 입력에 전달한다. 모델의 웹 도구는 호출하지 않는다. 기본 모델은 GPT-6 Luna이며, `OPENAI_POSTING_MODEL`로 바꿀 수 있다.

서버는 Responses API의 Structured Outputs로 회사, 직무, 마감일과 시각, 공고 항목, 전형, 자소서 문항을 받는다. 근거가 없는 값은 빈 문자열이나 빈 배열로 둔다. 화면은 서버 값으로 초안을 채우고, 원문 링크·확보한 본문·첨부 이미지로 내용을 확인할 수 있게 한다. 재시도 시점까지 사용자가 수정한 값은 보존한다.

- [x] [API 명세](../api/README.md)에 응답 필드를 추가하고, 기존 경로와 작업 상태를 유지했다.
- [x] Java에서 입력별 Responses API 요청과 응답 검증을 연결했다. 첫 링크의 전체 요청 한도는 27초이며 이미지 작업은 접수 후 23초 안에 종료한다.
- [x] React 확인 화면이 서버의 공고 항목과 전형을 표시한다.
- [x] 테스트 응답으로 입력·오류 계약을 검증하고, 실제 Luna에 공개 공고 링크와 샘플 이미지를 보냈다.

[OpenAI Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs) · [OpenAI 이미지 입력](https://developers.openai.com/api/docs/guides/images-vision)

## 기능 검증

- 백엔드 테스트 21개, 프론트 테스트 87개와 빌드가 통과했다. 테스트용 모델에 연결한 앱에서 httpYac 요청 7건과 브라우저의 링크·재시도·첨부 흐름을 확인했다. 내부 IP URL은 400으로 거절했다.
- 실제 KP한석화학 공고 한 건에서 회사명, 경력 요건, 마감일과 전형 3개를 확인했다. 요청부터 API 응답까지 7.8초였다.
- 한글 PNG 샘플은 첫 요청에서 회사명을 한 음절 다르게 읽었다. 원문 표기 지시를 추가한 뒤 같은 이미지에서 회사명, 직무, 마감일·시각과 경력 요건을 확인했다. 접수부터 완료 조회까지 5.1초였다.
- 설정으로 `gpt-5.4-mini-2026-03-17`을 선택해 같은 입력에 대해 실제 호출했다. KP 링크는 6.4초였고 회사명·마감일·경력 요건·전형 3개를 확인했다. 직무명에는 회사명도 포함됐다. 샘플 이미지는 2.0초였고 회사명·직무·마감일·시각·경력 요건을 확인했다.
- 시간은 요청 한 건씩 확인한 결과다. 배포 후 응답 시간 목표와 동시 요청 처리량은 실제 사용 환경에서 확인해야 한다.
