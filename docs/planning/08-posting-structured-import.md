# 공고 가져오기 JSON 구조화

링크는 HTTP로 표준 공고 데이터와 상세 텍스트를 읽고, 필요한 경우 Chromium에서 동적 본문과 상세 iframe을 확인한다. 첨부 이미지와 공고 본문 이미지는 별도의 OCR 없이 모델의 이미지 입력에 읽혀 텍스트와 함께 전달한다. 기본 모델은 GPT-5.4 mini이며, `OPENAI_POSTING_MODEL`로 바꿀 수 있다.

서버는 Responses API의 Structured Outputs로 회사, 직무, 마감일과 시각, 공고 항목, 전형, 자소서 문항을 받는다. 근거가 없는 값은 빈 문자열이나 빈 배열로 둔다. 화면은 서버 값으로 초안을 채우고, 원문 링크·확보한 본문·첨부 이미지로 내용을 확인할 수 있게 한다. 여러 직무가 확인되면 원하는 직무를 먼저 선택하고 내용을 수정할 수 있다.

- [x] [API 명세](../api/README.md)에 응답 필드를 추가하고, 기존 경로와 작업 상태를 유지했다.
- [x] Java에서 입력별 Responses API 요청과 응답 검증을 연결했다. 첫 링크의 전체 요청 한도는 27초이며 이미지 작업은 접수 후 23초 안에 종료한다.
- [x] React 확인 화면이 서버의 공고 항목과 전형을 표시한다.
- [x] 테스트 응답으로 입력·오류 계약을 검증하고, 실제 Luna에 공개 공고 링크와 샘플 이미지를 보냈다.

## 첫 구현 검증 기록

- 백엔드 테스트 21개, 프론트 테스트 87개와 빌드가 통과했다. 테스트용 모델에 연결한 앱에서 httpYac 요청 7건과 브라우저의 링크·재시도·첨부 흐름을 확인했다. 내부 IP URL은 400으로 거절했다.
- 실제 KP한석화학 공고 한 건에서 회사명, 경력 요건, 마감일과 전형 3개를 확인했다. 요청부터 API 응답까지 7.8초였다.
- 한글 PNG 샘플은 첫 요청에서 회사명을 한 음절 다르게 읽었다. 원문 표기 지시를 추가한 뒤 같은 이미지에서 회사명, 직무, 마감일·시각과 경력 요건을 확인했다. 접수부터 완료 조회까지 5.1초였다.
- 설정으로 `gpt-5.4-mini-2026-03-17`을 선택해 같은 입력에 대해 실제 호출했다. KP 링크는 6.4초였고 회사명·마감일·경력 요건·전형 3개를 확인했다. 직무명에는 회사명도 포함됐다. 샘플 이미지는 2.0초였고 회사명·직무·마감일·시각·경력 요건을 확인했다.
- 시간은 요청 한 건씩 확인한 결과다. 배포 후 응답 시간 목표와 동시 요청 처리량은 실제 사용 환경에서 확인해야 한다.
## 공고 본문과 여러 모집 직무

- [x] 원티드의 최초 HTML에 포함된 상세 필드와 사람인의 공개 상세 페이지에서 본문과 전형을 확보한다.
- [x] 렌더링이 필요한 공고는 Chromium으로 읽고, 본문에 표시된 상세 펼치기 버튼을 누른다. 긴 이미지 한 장은 위에서 아래로 조각을 만들어 한 번의 모델 요청에 담는다. 지원 범위를 벗어나는 이미지는 직접 입력으로 안내한다.
- [x] 모델 응답에서 공통 항목과 개별 모집 직무를 분리한다. 확인 화면에서 직무를 하나 선택하면 공통 항목과 해당 직무의 항목을 함께 채운다.
- [x] 링크 재시도 버튼과 API를 제거했다. 첨부 이미지는 작업 등록과 상태 조회 API를 사용한다.

기본 모델 GPT-6 Luna와 설정을 바꾼 `gpt-5.4-mini-2026-03-17`로 실제 공고 3건에서 확인했다. 원티드 398968의 전형 6개, 사람인 55390159의 전략기획 직무와 전형 3개, 우미건설 134409의 모집 직무 8개와 전형 5개를 가져왔다. Luna 응답에서 우미건설의 전기 직무에 전기기사 요건이 들어가고 토목기사 요건은 섞이지 않는 것도 확인했다.

백엔드 테스트 24개, 프론트 테스트 87개와 빌드를 통과했다. httpYac으로 잘못된 요청·내부 주소 거절과 제거한 두 경로의 404를 확인했다. 390px 브라우저 화면에서 직무 선택 전 등록이 막히고, 선택한 직무와 해당 요건이 등록되는 것을 확인했다.

## 사이트 공통 수집과 모델 비교

- 표준 `JobPosting` 데이터, 공개 상세 텍스트, 렌더링한 상세 iframe을 텍스트 경로에서 읽는다. 본문 후보 이미지는 텍스트와 함께 모델에 전달한다. 사람인은 상세 문서를 직접 받아 읽는다. 원티드의 접힌 전형과 문항은 동일한 공고 번호의 내장 데이터에서 확보했다.
- 같은 우미건설 이미지 조각을 보낸 모델 비교에서 GPT-5.4 mini는 11.89초, Luna는 15.90초였다. 원본 한 장을 mini에 보내면 6.40초였지만 직무 8개 중 2개만 읽고 마감 연도를 잘못 추출했다. 글자 판독에 필요한 이미지 조각을 유지한다.
- 잡코리아는 iframe에서 업무·경력 요건·우대 사항과 전형을 확인했다. 카카오와 카카오스타일의 자체 채용 페이지도 공개 상세 본문으로 확인했다. 원티드·사람인·우미건설을 포함한 실제 링크는 일회성 수동 검증에만 사용하고, 자동 테스트는 실제 사이트나 모델 API에 접속하지 않는다.
