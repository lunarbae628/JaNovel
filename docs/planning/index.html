JaNovel 제품 기획

작성일 2026-10-15 · 수정일 2026-11-25 · v1.25 · 공고 가져오기 JSON 구조화 반영

JaNovel은 공고, 자소서 수정 이력, 제출본, 일정과 면접 준비를 지원 건별로 관리한다. 핵심은 자소서에서 무엇이 바뀌었는지 빠르게 확인하고, 제출할 답변을 면접에 다시 쓰는 것이다. 첫 사용자는 여러 공고에 지원하며 자소서를 반복해서 수정하는 본인이다. 프론트 실행 · 백엔드 실행 · Figma 참고 화면

현재 구현

React 미리보기가 동작하며 지원 건은 브라우저에 저장된다. 백엔드는 PostgreSQL에 Flyway 초기 마이그레이션 하나를 적용하고, 테이블 11개를 Java JPA 엔티티에 매핑했다. 공개 공고에서 읽은 본문과 첨부 이미지를 GPT-5.4 mini로 구조화한다. 지원 건 저장 API와 서버 인증은 다음 단계다. 백엔드 가이드

공고와 지원 현황

  • 공개 공고 링크를 가져오면 읽을 수 있는 회사·직무·마감일과 공고 항목을 확인 화면에 채운다. HTML에서 본문을 못 읽으면 브라우저로 렌더링한다. 이미지로 게시된 본문은 나눠서 같은 모델에 전달한다. 모집 직무가 여러 개면 지원할 직무를 고르고, 부족한 내용은 원문을 보며 직접 입력할 수 있다. 확인 화면에서 회사·직무·마감일과 선택 시각, 공고 항목, 채용 단계와 문항별 글자 수를 수정한다. 주요 업무·지원 요건·우대 사항 같은 공고 항목은 제목과 본문을 자유롭게 정해 추가·수정·삭제·재정렬한다.
  • 목록에서 공고별 단계와 최종 합격·불합격·지원 취소를 선택하고 현황을 필터링한다. 사용자 정의 결과 옵션과 종료 당시 전형 단계는 DB 스키마에 반영했다. 화면과 서버 연동은 다음 단계다. 공고 등록 · 지원 현황

자소서·버전·제출본

  • 지원 목록이나 자소서 작성 화면에서 내 공통 자소서를 열어 문항과 초안을 작성한다. 문항이 없는 공고를 등록할 때 해당 지원 건으로 복사할 수 있다.
  • 문항마다 독립 버전, 자동 저장되는 초안과 스냅샷을 관리한다. 스냅샷은 저장 시점의 답변 전문이며 이름·설명은 정보 버튼에서 확인한다. 저장한 본문을 편집하면 같은 버전의 초안에 반영한다. 수정 중인 초안이 있을 때는 충돌을 알리고 새 버전으로 작성할 수 있게 한다.
  • 버전별 초안과 스냅샷 중 두 기록을 선택해 비교한다. 변경 구절을 초안에 적용하거나 두 본문을 조합해 독립된 새 버전과 첫 스냅샷을 만든다. 전체 그래프에서 조합에 참고한 버전과 당시 본문을 볼 수 있다. 개별 스냅샷은 해당 버전의 마지막 기록이고 다른 기록이나 버전의 참조가 없을 때 삭제할 수 있다. 버전은 하나 이상 남기며, 버전을 삭제할 때 이어질 수 있는 이력은 남은 조상으로 연결한다. 조합 버전은 복사한 출처 본문을 보존한다. 작성 화면 · 버전과 조합 · 삭제 규칙
  • 작성 화면의 별로 문항별 제출본을 지정한다. 제출본 버튼으로 같은 지원 건의 모든 문항을 보고, 지정된 문항에서 제출본 수정으로 본문을 고치거나 확인 후 교체한다. 원본 버전을 고쳐도 지정한 답변 본문은 유지된다. 전체 제출본과 현재 문항을 각각 미리보거나 브라우저 인쇄 메뉴로 PDF 저장할 수 있다. 작성 화면의 면접 연습에서 지정된 제출본을 재사용한다. PDF · 제출본 모델

캘린더와 할 일

  • 개인 일정·체크리스트와 지원 건의 마감·면접 등 일정을 한 달력에 표시한다. 빈 날짜를 더블클릭하거나 날짜 범위를 드래그해 추가하고, 일정이나 달력 아래 선택 날짜 목록에서 수정·삭제한다. 일정에는 제목, 기간·시간, 메모와 색상 등을 지정한다. 색상 범례는 생략한다.
  • 기간 일정은 종료 날짜를 포함한다. 같은 요일 열을 위아래로 드래그하면 매주 반복 일정으로 열리고 드래그의 마지막 날짜를 종료일에 채운다. 매일 또는 매주 반복은 종료일까지 이어지며 종료일을 비우면 계속 반복한다. 특정 날짜만 수정하거나 건너뛰기, 전체 반복 수정, 체크리스트 회차별 완료·취소를 지원한다. 지원 마감 일정의 삭제는 해당 지원 건의 마감일·시각을 비운다. 일정 화면 · 반복 규칙

면접 준비와 모의면접

  • 지원 건별로 예상 질문과 텍스트 답변을 관리한다. 질문을 고르면 같은 화면에서 본문을 바꾸며 질문마다 녹음을 남겨 다시 듣거나 교체·삭제할 수 있다.
  • 모의면접은 예상 질문 연습과 자료 기반 연습으로 나뉜다. 자료 기반 연습은 지정 제출본, 붙여넣은 이력서·포트폴리오·자소서 본문, 텍스트를 읽을 수 있는 PDF·TXT·MD에서 브라우저 규칙으로 질문을 만든다. 질문에 인용된 부분은 연습 기록에 남는다. 음성 합성이 질문을 읽을 때만 남색 입자 구가 움직인다. 듣기·일시정지·다음 질문·종료를 질문 옆에 모았고 연습한 질문과 진행 시간을 기록한다. 실제 답변 인식·AI 꼬리 질문과 전사는 AI 음성 연결 계획에 속한다. 면접 준비 · 자료 입력 · 연습 진행

친구·커뮤니티·수신함

  • 친구 화면 왼쪽에서 예시 계정을 검색·추가하고, 오른쪽에서 친구 캘린더 또는 채팅을 사용한다. 이메일 초대는 브라우저에 대기 상태로 표시한다. 친구의 일정과 할 일 상태를 보고 댓글을 남긴다. 수신함은 사이드바에서 모달로 열며 읽지 않음 보기, 모두 읽음, 예시 친구 요청 수락·거절, 채팅·일정 바로가기를 지원한다.
  • 커뮤니티는 자유·질문·스터디 모집·합격 후기 말머리의 게시판이다. 목록은 제목을 먼저 보여주고 작성자·날짜는 보조 정보로 표시한다. 별도 글쓰기 화면, 상세·댓글과 예시 스터디 참여 신청을 지원한다. 친구·대화·게시판 입력은 로컬 미리보기에서 유지된다. 친구 · 수신함 · 게시판

AI 피드백·인증·저장

  • 작성 화면에서 선택한 공고·문항·본문과 요청을 복사하고, 외부 AI 응답과 수정안을 붙여 넣어 비교할 수 있다. 제품 안의 실제 AI 모델 호출이나 MCP 서버는 설계 단계다.
  • 이메일 로그인·가입·비밀번호 재설정과 Google 로그인은 로컬 화면 시연이다. 가입은 이메일 확인과 계정 정보 입력으로 나뉜다. 지원·작성·캘린더 데이터는 localStorage에, 공고 이미지와 질문별 녹음은 IndexedDB에 둔다. 설정에서 JSON 백업을 내보내거나 가져오며 가져오기는 해당 작업공간을 교체한다. 첨부 파일은 별도 브라우저 저장소에 있다. 피드백 패널 · 인증 화면 · 저장

확정한 제품 계획

공고 수집과 지원 상태

  • 공고의 URL·이미지·텍스트 원문과 사용자가 확인한 입력값을 함께 보관한다. 자동으로 채운 항목은 사용자가 확인·수정하게 한다. 대표 마감 방식은 날짜 지정·수시채용·채용 시 마감·상시 접수 중 하나로 관리한다. 미입력은 NULL로 저장한다. 수시채용도 공고에 명시된 마감일·시각을 함께 저장할 수 있으며, 공고에 없는 마감 시각이나 전형은 비워 둔다.
  • 공통 진행 상태는 관심·작성 중·제출·전형 진행·종료로 관리한다. 현재 전형은 해당 지원 건의 채용 단계에서 고르고, 전형 순서나 일정만으로 통과·제출을 확정하지 않는다. 종료 당시 결과 옵션과 단계 이름을 남긴다.
  • 기본 결과는 최종 합격·불합격·지원 취소다. 사용자가 결과를 추가·수정·삭제하고 이름·색·순서를 정할 수 있게 한다. 결과 옵션은 사용자 단위로 관리해 여러 지원 건에서 재사용한다. 옵션을 비활성화해도 과거 지원 결과에 표시한다.

자소서와 제출본

  • 지원 건과 문항 단위로 작성 공간을 분리한다. 기존 문항은 등록 순서를 유지한다. 자동 저장은 버전의 현재 초안을 갱신하고, 스냅샷에는 그 시점의 답변 전문을 고정한다. 복원·편집에서도 저장된 원본을 보존한다. 비교·조합은 구절 단위로 진행하며 결과는 새 버전의 첫 기록으로 남긴다.
  • 서버의 조합 출처는 실제 입력 스냅샷을 식별한다. 작성 중 본문을 입력으로 쓸 때는 그 시점의 전문을 먼저 고정한다. 조합 결과와 부모 링크는 한 번에 저장한다. 부모 버전이 삭제되면 관련 링크를 정리하고 자식 버전 본문과 다른 부모 연결을 보존한다. 모든 부모가 사라진 자식은 독립적으로 남을 수 있다.
  • 문항당 현재 제출본 하나를 둔다. 지정할 때 답변을 복사하고, 그 본문을 따로 수정하거나 다른 버전으로 교체할 수 있게 한다. PDF와 자료 기반 면접은 같은 데이터를 읽는다. PDF에는 회사·직무·문항·답변을 출력하고 한글과 긴 답변의 페이지 분할을 검증한다. 실제 지원 사이트 접수는 사용자가 진행한다.

일정과 개인 할 일

  • 개인 일정은 지원 건 없이 만들 수 있고, 체크리스트 완료와 지원 단계는 독립적이다. 기간·선택 시각·종일·색상과 반복 일정을 유지한다. 반복 유형을 바꿔도 지정한 종료일을 유지한다. 종료일이나 종료 시각이 시작보다 빠르면 입력을 보존하고 조건을 안내한다. 회차 편집과 전체 수정에서 기존 완료 이력을 보호한다.
  • 주·월 경계에서 기간을 나눠 표시하되 하나의 일정으로 수정한다. 마감·면접·과제 일정은 해당 지원 건에 연결한다. 전형 순서를 다시 고쳐도 기존 일정과 단계 이동 기록의 연결을 유지한다. 날짜가 미정인 일정도 확인할 수 있게 한다.

웹 내부 개인 AI 피드백

  • 첫 실사용 버전(1차)의 목표는 사용자가 ChatGPT 계정으로 로그인(Sign in with ChatGPT)해 JaNovel 웹 안의 채팅에서 AI와 대화하고, JaNovel에 저장된 선택한 공고·문항·답변을 참고해 수정 후보를 받는 것이다. 2차 목표는 같은 채팅에서 사용자 PC의 로컬 AI에 접근하는 것이며, 중계 서버와 기기 연결 프로그램, 제품 MCP를 둔다. 사용자가 허용한 로컬 자료는 2차에서 다룬다. 맥락 복사·붙여넣기는 현재 품질과 흐름을 확인하는 수단이다.
  • 피드백에는 원본 답변의 식별자, 평가 기준 버전, 대상 구절, 이유·근거와 제안을 기록한다. 실제 경험과 본인 기여, 문항·직무 적합성, 문장 품질의 세 기준을 평가하며 근거가 부족하면 사용자에게 확인을 요청한다. 수정 후보는 비교 후 사용자가 채택할 때 새 기록에 반영한다. 원본이 바뀌었으면 다시 비교하고, 재시도는 결과 중복을 방지한다. AI 연결과 MCP 설계

1인 AI 음성 모의면접

  • 예상 질문·답변·질문별 녹음은 면접 준비 화면에 둔다. AI 모의면접은 등록한 질문으로 시작하는 예상 질문 연습과 사용자가 고른 제출본·이력서·포트폴리오에서 질문을 만드는 자료 기반 연습을 유지한다. 질문이 참고한 문항이나 자료를 표시한다. 제출본이 없을 때 현재 작성본을 쓸지는 사용자가 선택한다.
  • AI 음성 API를 연결한다. 질문 읽기, 마이크 답변 인식, 답변 기반 꼬리 질문, 일시정지·재개, 종료 후 전사·질문별 피드백을 제공한다. 타이핑 답변 기록은 예상 질문 화면에서 다룬다. 질문할 때만 입자 구를 움직이고, 현재 질문 가까이에 종료와 진행 제어를 둔다. 준비 메모, 질문별 녹음, 연습 전사와 제출본은 각각 보관한다. 질문별 녹음 교체는 새 파일 저장이 끝난 뒤 적용한다.
  • 마이크 권한 거절, 답변 인식 중단, 재연결·종료와 저장 실패 때의 행동을 정한다. 피드백은 빠진 근거, 불명확한 역할과 설명하지 못한 기술 선택을 짚는다. 음성 제공자와 원음 저장·보관 정책, 한국어 인식 품질·응답 지연·회차당 비용은 실제 연결 실험에서 확인한다.

친구와 커뮤니티의 서버 연동

  • 친구 검색·요청·수락, 채팅, 캘린더 일정 댓글과 수신함을 실제 계정에 연결한다. 친구 캘린더는 기본 비공개이며, 사용자가 고른 일정·할 일의 상태를 친구가 본다. 회사·직무와 메모의 공개 범위도 선택하고, 공유를 철회하거나 친구 관계를 해제하면 이후 조회 권한에 반영한다.
  • 모집 글은 목적·일정·인원·조건을 받고 모집자가 신청과 마감 상태를 관리한다. 참가한 스터디는 일정과 채팅에서 준비를 이어간다. 합격 후기는 작성자가 공개할 회사·직무·전형과 준비 방법을 선택한다. 댓글과 알림은 작성자 및 대상의 읽기 권한을 확인한다.

장기 계획 · 친구와 AI가 함께하는 다인 면접

기존 JaNovel 기능 이후 착수한다. 회사별 면접 준비에서 진입하고, 고른 공고·제출본·예상 질문을 연습에 가져온다. 방의 설정 공개 범위와 참가자 개인 자료 접근은 각각 정한다.

  1. 방 설정. 일대일·일대다·다대일·다대다 유형이나 지원자·면접관 수를 정한다. 공통·지정 질문, 기출, 분위기, 면접 길이와 답변 제한 시간을 입력한다. 사용자 입력과 AI가 보완한 설정을 표시하고, 정보가 적으면 기본 조건부터 시작할 수 있게 한다.
  2. 대기실. 혼자 들어가거나 친구를 링크로 초대한다. 사람에게 지원자·면접관 역할을 배정하고 남은 자리에 AI를 배치한다.
  3. 진행. 좌석, 발화자, 마이크와 타이머를 보인다. 공통 질문은 순서대로 진행하고 개별 지목과 꼬리 질문을 지원한다. 사람과 AI가 지정된 차례에 답한다. 참가자 화면의 진행 상태와 발언 순서를 맞추고 연결이 끊긴 사람의 복귀를 검증한다.
  4. 복기. 질문·답변·내 꼬리 질문·발화 시간과 다시 연습할 질문을 확인한다. 참가자별 복기 자료의 공개 범위를 정하고 같은 조건 또는 바꾼 조건으로 다시 연습한다.
