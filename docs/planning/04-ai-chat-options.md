# AI 채팅 위치와 사용자 비용 경로

2026-11-08 · 공식 OpenAI 문서 재확인 · 서비스 내부 채팅은 사용자 확정, 실행·인증 방식은 검증 전

후속 검토: [웹 내부 채팅과 고객 로컬 에이전트 연결](05-local-agent-chat-review.md). 중간 서버에 MCP와 작업 중계를 함께 두고 고객 PC 연결 프로그램으로 지원되는 에이전트를 호출하는 구성을 권고한다. Codex app-server·ACP는 후보이며 실제 연결 성공·공개 서비스 제공 자격을 확인한 것은 아니다. 신규 구현은 MCP Sampling에 의존하지 않는다.

## 구분

MCP는 서비스 자료·도구를 AI에 연결한다. ChatGPT에 JaNovel을 연결하면 사용자는 ChatGPT에서 대화하며 공고·문항·버전을 조회하고 후보를 반환할 수 있다. JaNovel 웹사이트 안에서 ChatGPT를 실행할 권한을 MCP 연결만으로 얻는 것은 아니다.

MCP Apps UI는 서비스 화면을 ChatGPT 대화 안에 표시할 수 있다. 자소서 선택·차이 확인·채택 같은 작은 UI를 붙이는 후보가 된다. ChatGPT 채팅을 JaNovel 사이트 안으로 가져오는 것과는 방향이 다르다. [공식 MCP UI 안내](https://developers.openai.com/plugins/build/chatgpt-ui)

## 선택지

| 방식 | 대화 위치 | 모델 이용 경로 | JaNovel에 대한 판단 |
| --- | --- | --- | --- |
| 외부 ChatGPT + MCP | ChatGPT | 사용자의 ChatGPT 이용 조건 | 보조 연동 후보. 필수 웹 내부 채팅의 기본 경로로 삼지 않음 |
| 사용자 API 키 연결 | JaNovel | 사용자의 API 계정 | 내부 채팅이 필요할 때 선택 기능으로 제안. 키 발급·결제 설정·사용량 안내가 진입 부담 |
| 서비스가 API 제공 | JaNovel | 서비스의 API 계정 | 일반 사용자에게 편하지만 서비스가 비용·허용량을 관리해야 하므로 현재 추가 지출 제약과 비교 필요 |
| Sign in with ChatGPT | 자격을 충족하는 앱 | 사용자가 별도로 승인한 ChatGPT 구독 사용량 | 개인용 검증 후보. 공개 호스팅 서비스 제공 자격과 구분 |

API 키 연결은 사용자의 ChatGPT 구독을 연결하는 동작이 아니다. API 호출의 비용·한도는 해당 API 계정 조건을 따른다. 사용자의 기존 ChatGPT 대화·기억이 API 키에 포함되어 넘어온다고 설계하지 않는다. 경험 자료와 필요한 대화 맥락은 사용자가 선택해 제공하고 서비스가 관리한다. API 이용료를 서비스가 내지 않아도 서버·저장·키 관리 비용은 남는다. [API 운영 안내](https://developers.openai.com/api/docs/guides/production-best-practices)

공식 SIWC 안내는 로그인과 구독 사용 권한을 구분한다. 적격 Plus·Pro 사용자가 허용된 앱에서 구독 사용량을 승인할 수 있으나 대화·기억 접근 권한을 주지는 않는다. 현재 공식 가이드는 오픈소스·로컬 개인 프로젝트와 유료·원격 호스팅 앱의 접근 신청을 구분한다. JaNovel이 공개 웹서비스로 사용할 수 있다고 아직 확정하지 않는다. 사용자당 API 키를 받지 않는 공식 대안으로 별도 검증할 가치가 있다. [SIWC 개요](https://developers.openai.com/siwc/quickstart) · [통합 가이드와 제공 조건](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt?site_locale=en)

## 사용자 확정 요구와 검토할 경로

사용자는 고객의 개인 AI 에이전트를 JaNovel 웹사이트 안에서 채팅으로 사용하고, 그 에이전트가 허용된 로컬 자료를 참고하며, 서비스는 작업 결과·근거·수정 버전을 정리하는 경험을 요구했다. 외부 ChatGPT로 이동하는 흐름을 기본으로 삼지 않는다. 사용자 API 키 입력 자체를 제품의 핵심 요구로 바꾸지 않는다.

중간 MCP 서버를 둘 수 있다는 사용자 아이디어를 설계 후보로 기록한다. 이 서버는 공고·문항·버전·가이드 조회와 수정 후보 반환을 중계할 수 있다. 웹 채팅의 작업을 고객 에이전트에 전달하고 응답·진행 상황·중단을 연결하는 실행 경로는 별도 검증 대상이다. MCP 서버를 등록했다는 사실만으로 기존 ChatGPT Work 앱을 웹사이트에서 원격 조작할 수 있다고 가정하지 않는다. 고객 PC의 연결 프로그램이나 지원되는 에이전트 연동을 포함해 한 경로를 먼저 시험하는 것을 권고한다.

네 가지 AI 경로를 동시에 구현하지 않는다. SIWC·API·에이전트별 실행 인터페이스는 실제 권한·사용량·제공 자격을 검증하기 전에는 완료 기능으로 표시하지 않는다. 어떤 경로든 수정 후보 저장 → 바뀐 낱말·구절 비교 → 사용자가 새 스냅샷으로 채택하는 구조를 공통으로 유지한다. 이 문서에서는 에이전트 실행이나 중간 MCP 서버를 구현하지 않았다.

이번에는 문서를 조회했으며 모델 호출·키 입력·과금·제품 MCP 구현은 수행하지 않았다. 디자인 도구인 Talk to Figma 연결과 제품 MCP 검증을 구분한다.
