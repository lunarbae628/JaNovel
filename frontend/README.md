# JaNovel 프론트엔드

React·Vite로 만든 브라우저 미리보기다. 기능별 현재 동작과 다음 개발 범위는 [제품 기획](../docs/planning/01-product-plan.md)에 정리되어 있다.

## 실행

저장소 루트에서 실행한다.

```sh
npm --prefix frontend ci
npm --prefix frontend run dev
```

[지원 현황](http://127.0.0.1:5173/#/applications)을 열고 로그인 화면에서 **둘러보기**를 선택한다. 브라우저 저장소는 호스트와 포트별로 나뉜다. 기존에 5187 포트를 사용했다면 `npm --prefix frontend run dev -- --port 5187`로 같은 주소를 연다.

**공고 가져오기**를 쓰려면 [백엔드](../backend/README.md)를 8080 포트에서 함께 실행한다. 백엔드에 직접 요청할 때는 성공하는데 Vite 경유 요청이 404라면, Vite를 재시작해 현재 프록시 설정을 불러온다.

라링크와 이미지 가져오기는 백엔드의 `OPENAI_API_KEY` 설정이 필요하다. 한 공고에 모집 직무가 여러 개면 확인 화면에서 지원할 직무를 고른다. 대기 화면에는 예상 진행률과 경과 시간이 표시되고, 기다리는 동안 **직접 입력하기**를 선택할 수 있다.

문항 자동 채움과 제보는 백엔드를 [로컬 프로필](../backend/README.md#자소서-문항-자동-채움-미리보기)로 실행하면 확인할 수 있다. 같은 공고 상세 주소와 직무로 내용을 확인하면 이전에 입력한 문항이 채워진다. 이미지 공고도 확인 화면의 **지원 링크**에 공고 상세 주소를 추가하면 문항을 재사용할 수 있다.

문항을 비워 두고 **공고 등록**을 누르면 지원 기록이 저장된다. 지원 상세에서 **문항 추가**로 돌아와 문항을 입력할 수 있다.

지원 목록이나 자소서 작성 화면의 **내 공통 자소서**에서 질문과 답변 초안을 작성해 저장한다. 자유문항 공고에서 불러오면 해당 지원 건의 개인 문항과 작성안에 복사된다.

캘린더에서 다른 요일을 가로로 드래그하면 연속 일정을, 같은 요일의 서로 다른 주를 세로로 드래그하면 매주 반복 일정을 추가한다. 세로 드래그의 마지막 날짜가 **종료일**에 채워지며 일정 추가 창에서 바꿀 수 있다.

일정 바를 한 번 클릭하면 상세 보기가 열리고(수정·삭제·완료 표시 가능), 더블클릭하면 바로 수정한다. 반복이 아닌 일정은 바를 마우스로 끌어 다른 날짜로 옮길 수 있다. 달력 아래 주간 패널은 오늘 기준 이번 주를 보여 주며 이전·다음 주로 이동할 수 있다.

## 브라우저 데이터

- 지원·자소서·제출본·일정은 localStorage의 `janovel.frontend.v1` 저장 공간을 사용한다. 다른 브라우저나 기기에서는 저장 공간이 다르다.
- 이미지와 질문별 녹음은 IndexedDB에 저장한다. 설정의 JSON 백업으로 지원·작성 데이터를 내보낼 수 있으며 첨부 이미지와 녹음은 백업 파일에 포함되지 않는다.
- 로그인·Google·메일 인증, 친구·채팅·커뮤니티는 로컬 시연이다. 회원가입 화면의 예시 인증번호는 `123456`이다.
